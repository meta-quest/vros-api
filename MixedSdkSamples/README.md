# Mixed SDK Samples

This directory contains samples demonstrating the usage of multiple SDKs from the Horizon OS SDK within a single application.

## Samples

| Name | SDKs | Description |
| ---- | ---- | ----------- |
| [Horizon OS SDK Versioning](./VersioningSample/) | JSDK<sup>1</sup>, Support Library<sup>2</sup> | Demonstrates querying the version of Horizon OS SDK on the device with JSDK, and comparing it to a constant value with Support Library |

1. **JSDK:** Horizon OS Java Software Development Kit
2. **Support Library:** Horizon OS Support Library
