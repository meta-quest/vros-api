# Horizon OS Java Software Development Kit samples

This directory contains samples demonstrating the [**Horizon OS JSDK**](https://developers.meta.com/horizon/documentation/android-apps/horizon-os-jsdk).

For samples that intentionally combine the JSDK with other surfaces (NSDK, Support Library), see [`MixedSdkSamples/`](../MixedSdkSamples/) at the repo root.

## Samples

| Name | Description |
| ---- | ----------- |
| [Stereo Video Sample](./StereoVideoSample/) | Demonstrates stereo composition for mono, side-by-side, and top-bottom video with `VideoView` and `SurfaceView`. |
