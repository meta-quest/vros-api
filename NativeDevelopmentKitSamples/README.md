# Native Development Kit samples

This directory contains samples demonstrating the **Horizon OS NSDK**.

For samples that intentionally combine the NSDK with other surfaces (JSDK, Support Library), see [`MixedSdkSamples/`](../MixedSdkSamples/) at the repo root.

## Samples

- [Virtual Camera Publisher](VirtualCamera) — Demonstrates the Virtual Camera Publisher API: registering a publisher, producing frames into an `AHardwareBuffer`, and handling the publisher lifecycle.
